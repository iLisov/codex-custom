# Codex Custom

Форк `openai/codex` с изменениями CLI. Проверенная база: `rust-v0.162.1`.
Наши изменения находятся в ветке `custom`; `main` сохраняется для синхронизации с OpenAI.

- Наведение и клик по модели, permissions и кнопке Settings.
- Строка текущего действия вместо одного Working.
- `/settings`: краткость ответов, сообщения о работе, вывод команд, проверки, автосводки, интерфейс и статус.
- В вариантах указано влияние на токены и контекст.
- Длинный полученный вывод команд сохраняется в файл при заданном лимите.
